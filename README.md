# Compendio Técnico en Accesibilidad Web

React + Vite. Texto y datos genéricos.

## Uso

    npm install
    npm run dev

Para generar la versión final:

    npm run build

## Estructura

    src/
      main.jsx                  entrada de la app
      App.jsx                   rutas
      components/               Header, Footer, PageHero, cards, filtros, plantilla de subpágina
      pages/                    Home y las 4 subpáginas
      data/                     estructura del sitio y contenido genérico (aquí se cambia el texto)
      styles/global.css         estilos

## Páginas

- `/` Entendiendo la discapacidad
- `/materiales-accesibles` Cómo hacer materiales accesibles
- `/clases-en-linea` Clases en línea
- `/videos-recapacita` Videos Recapacita
- `/dentro-del-aula` Dentro del aula
